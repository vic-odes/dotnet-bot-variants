# Championnat des mascottes — tirage et calendrier

Généré par `node championnat/tirage.mjs` (graine `championnat-dotnet-bot-2026`, données : `tirage.json`).

**Format** : phase de poules (chaque combattant affronte tous ceux de sa poule ; victoire = 3 points), puis élimination directe pour les 2 premiers de chaque poule : quarts, demies, finale. Une vidéo par combat, 9:16, 90 s. 28 vidéos au total.

## Chapeaux

1. dotnet-bot (.NET / C#) · Duke (Java) · Tortue-fusée (Node.js) · Poney (Django / Python)
2. elePHPant (PHP) · Gopher (Go) · Ferris (Rust) · Kodee (Kotlin)
3. Dash (Dart / Flutter) · Scratch Cat (Scratch) · Chameau (Perl) · Alien (Lisp)
4. Ziggy (Zig) · Lucy (Gleam) · Camelia (Raku)

dotnet-bot, tête de série, est placé d'office en poule A ; le chapeau 4 n'a que 3 combattants, une poule se joue donc à 3.
