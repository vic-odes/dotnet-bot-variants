# Mascottes des autres langages et frameworks

Mascottes des langages et frameworks voisins de .NET, pour les vidéos qui comparent les écosystèmes.
Elles **ne font pas partie de la charte .NET**. Dans un projet vidéo, copier dans `<projet>/assets/img/`
uniquement les fichiers utilisés.

- Chaque SVG est recadré sur son dessin et accompagné d'un **PNG 2048 px** (fond transparent) du même nom.
- Planche d'aperçu : `_planche.jpg`.
- Origine : **officiel** = fichier du projet, inchangé (hors recadrage) ; **redessiné** = vectorisé ici d'après l'officiel ;
  **création** = dessin original de ce dépôt, quand aucune version libre n'existe.
